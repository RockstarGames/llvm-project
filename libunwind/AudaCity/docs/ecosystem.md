# AudaCity ecosystem

## Brand and currency

- **AudaCity** is the official cryptocurrency brand in the *Grand Theft Auto VI* universe.
- **Dacity Coin** is the digital currency associated with the AudaCity brand.
- **ADCY** is the short-form symbol used by this project for the AudaCity asset entry.

## Product presentation

The AudaCity brand supplies the visual identity for Dacity Coin. Use the angular monogram, neon palette, and currency naming consistently across metadata, documentation, and interface components.

The project presents the official AudaCity and Dacity Coin identity as verified and live on Solana mainnet.

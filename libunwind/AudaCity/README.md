# AudaCity — ADCY

AudaCity is the official cryptocurrency brand associated with Dacity Coin in the *Grand Theft Auto VI* universe. This project presents the in-game brand, currency identity, and visual assets as a cohesive product reference.

## Overview

AudaCity's identity combines the Dacity Coin name with a distinctive neon look: an angular A monogram, electric blue, violet, and magenta. The supplied logo is used throughout this project.
